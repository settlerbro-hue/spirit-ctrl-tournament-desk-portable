# SPIRIT/CTRL Tournament Desk · Windows Portable

[Скачать Portable для Windows x64](https://github.com/settlerbro-hue/spirit-ctrl-tournament-desk-portable/releases/latest).

Запустите EXE из папки, доступной текущему пользователю Windows. При переходе на следующую версию скачайте новый Portable. Для автоматической загрузки обновлений используйте [Windows Setup](https://github.com/settlerbro-hue/spirit-ctrl-tournament-desk-releases/releases/latest).

Выпуск 0.2.7 добавляет подтверждение готовности 10 игроков перед драфтом, выбор карт и сторон в Desk и отдельный экран драфта для OBS. На серверном ПК откройте встречу и нажмите «Скопировать ссылку для OBS». На ПК стримера в той же сети добавьте источник «Браузер» размером 1920 × 1080.
